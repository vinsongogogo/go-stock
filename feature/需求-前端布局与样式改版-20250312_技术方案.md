## 2. 架构与模块

- **本期范围**：仅前端（`frontend/`）。无后端 API 或数据模型变更；Wails 绑定（`wailsjs/go/main/App`、`wailsjs/runtime`）沿用，无新增或变更。
- **涉及目录**：
  - `frontend/src/router/router.js` — 路由定义与重定向
  - `frontend/src/App.vue` — 根布局、侧栏菜单、activeKey、全局 Provider
  - `frontend/src/style.css` — 全局样式与变量（将被主题文件替代/合并）
  - `frontend/src/theme/` — **新增**，存放整套主题变量与入口
  - `frontend/src/components/*.vue` — 页面与公共组件，涉及路由名、query、类名、样式
- **依赖关系**：路由与重定向 → App.vue 菜单与 key → 各页面组件引用新 name/query；主题变量 → style.css 与各组件样式。
- **技术选型**：不引入新库。主题通过 Naive UI 的 `NConfigProvider` 的 `themeOverrides` + 新建 `theme/vars.css`（或 `theme/theme.js`）覆盖 CSS 变量与组件库主题；侧栏保持左侧，保留折叠、拖拽、跑马灯、loading 等交互。

## 3. 数据与接口

- **数据模型**：无。
- **API**：无变更；本期无新接口。
- **前端路由与状态**：
  - **路由表**：path 与 name 全部按需求文档附录 A.1 更换；默认采用附录 A.3 **方案一** 入口顺序（若产品选定方案二，仅调整 App.vue 中 menuOptions 顺序即可）。
  - **旧 path 兼容**：通过 router 的 `beforeEach` 或路由配置中的 `redirect`，将旧 path 重定向到新 path（见 5.1）。
  - **activeKey**：与路由 name 一致，使用新 name：`watchlist`、`discovery`、`funds`、`assistant`、`lab`、`preferences`、`info`；全屏/隐藏/退出等保留 `full`、`hide`、`exit`。
  - **query.name**：侧栏与子菜单跳转时使用的 `query.name` 与附录 A.2 新文案一致（用于 discovery 子 tab、lab 子 tab 等），见 5.2 与 6。

## 4. 跨域/对外协议

本期为纯前端改版，无新增后端或第三方接口。

| 域/系统 | 协议形式 | 说明 |
|---------|----------|------|
| 前端 ↔ Go (Wails) | Wails Call / EventsOn/EventsEmit | 沿用现有 `wailsjs/go/main/App`、`wailsjs/runtime`，无接口变更。事件名 `changeTab`、`changeMarketTab`、`changeResearchTab` 保持不变，仅传递的 `name` 字段改为新文案。 |

## 5. 代码级设计（含代码/伪代码）

### 5.1 路由：新 path/name + 旧 path 重定向

- **涉及文件**：`frontend/src/router/router.js`
- **逻辑**：定义新路由表；增加旧 path 到新 path 的 redirect，保证书签/深链访问旧 URL 时自动跳转新 path。

```javascript
// frontend/src/router/router.js
import { createRouter, createWebHashHistory } from 'vue-router'
import stockView from '../components/stock.vue'
import settingsView from '../components/settings.vue'
import aboutView from '../components/about.vue'
import fundView from '../components/fund.vue'
import marketView from '../components/market.vue'
import agentChat from '../components/agent-chat.vue'
import research from '../components/researchIndex.vue'
import cronTaskManager from '../components/cron-task-manager.vue'

const routes = [
  // 旧 path 重定向到新 path（兼容历史书签/深链）
  { path: '/', redirect: '/watchlist' },
  { path: '/market', redirect: '/discovery' },
  { path: '/fund', redirect: '/funds' },
  { path: '/agent', redirect: '/assistant' },
  { path: '/research', redirect: '/lab' },
  { path: '/settings', redirect: '/preferences' },
  { path: '/about', redirect: '/info' },
  { path: '/cron-tasks', redirect: { name: 'scheduler' } },
  // 新路由（附录 A.1）
  { path: '/watchlist', component: stockView, name: 'watchlist' },
  { path: '/discovery', component: marketView, name: 'discovery' },
  { path: '/funds', component: fundView, name: 'funds' },
  { path: '/assistant', component: agentChat, name: 'assistant' },
  { path: '/lab', component: research, name: 'lab' },
  { path: '/preferences', component: settingsView, name: 'preferences' },
  { path: '/info', component: aboutView, name: 'info' },
  { path: '/scheduler', component: cronTaskManager, name: 'scheduler' },
]

const router = createRouter({
  history: createWebHashHistory(),
  routes,
})

export default router
```

### 5.2 App.vue：菜单顺序、key、name、label、query 与 activeKey

- **涉及文件**：`frontend/src/App.vue`
- **逻辑**：
  - **入口顺序**：按附录 A.3 方案一：行情中心 → 自选列表 → 智能助手 → 研究 → 基金 → 偏好设置 → 关于我们。
  - **menuOptions**：每项 `key` 改为新 name（`discovery`、`watchlist`、`assistant`、`lab`、`funds`、`preferences`、`info`）；`label` 与 `RouterLink` 的 `to.name`、`to.query.name` 改为附录 A.2 新文案；`EventsEmit("changeMarketTab", …)` 等传递的 `name` 改为新文案。
  - **动态分组**：`item.key === 'stock'` 改为 `item.key === 'watchlist'`；`router.push({ name: 'stock', ... })` 改为 `name: 'watchlist'`；子项 `to.name` 均为 `watchlist`。

### 5.3 布局结构改版（主框架与子页面）

- **涉及文件**：`frontend/src/App.vue`，`frontend/src/components/researchIndex.vue`，`frontend/src/components/market.vue`，以及使用 `n-grid`/`n-card`/`n-tabs` 的页面组件。

### 5.4 整套主题与 CSS 改版

- **涉及文件**：新建 `frontend/src/theme/vars.css`；`frontend/src/style.css`（重写为引用 theme 并去掉旧变量与旧类名）；`frontend/src/App.vue` 的 `<style scoped>`；`frontend/index.html`（若需引入 theme）；各组件内使用到 `--sidebar-bg`/`--app-bg` 或 `.app-sidebar` 的改为新变量/新类名。
- **逻辑**：
  - **新主题变量**：统一使用新命名与色系，避免与旧版色值重复。示例（可替换为产品指定色系）：
    - `--surface-bg: #f0f4f8`（替代 --app-bg）
    - `--nav-bg: #e8ecf1`（替代 --sidebar-bg）
    - `--page-bg: #ffffff`（替代 --content-bg）
    - `--border-default: #dce0e6`
    - `--text-primary: #1a2332`
    - `--text-secondary: #5a6578`
    - 字体：`--font-sans: "DM Sans", "Segoe UI", system-ui, sans-serif`（替代 Inter）
  - **Naive UI 主题**：在 `App.vue` 的 `n-config-provider` 上通过 `:theme-overrides="themeOverrides"` 覆盖主色、菜单项颜色等，使组件库视觉与旧版明显不同（具体 overrides 对象在 theme 文件或 App.vue 中定义）。
  - **类名**：全局将 `.app-sidebar`、`.app-sidebar-menu` 替换为 `.main-nav`、`.main-nav-menu`；style.css 与 App.vue 中所有 `.n-layout-sider.app-sidebar` 改为 `.n-layout-sider.main-nav`，`.app-sidebar-menu` 改为 `.main-nav-menu`。
  - **FloatingAiAssistant、弹窗、settings、about**：使用同一套 `--surface-bg`、`--page-bg`、`--text-primary` 等变量；不保留 `--sidebar-bg`、`--app-bg` 等旧变量名。

**style.css 重写要点**：删除 `--app-bg`、`--sidebar-bg`、`--content-bg`、`--border-color` 及所有 `.app-sidebar` 相关规则；改为 `@import` 或在 index.html 先引入 `theme/vars.css`，再在 style.css 中使用 `var(--surface-bg)` 等，并仅保留对 `.main-nav`、`.main-nav-menu` 的必要覆盖（色值来自 vars.css）。
