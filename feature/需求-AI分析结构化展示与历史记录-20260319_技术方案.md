## 2. 核心设计决策

| 决策项 | 方案 | 理由 |
|--------|------|------|
| 结构化数据获取 | Prompt引导LLM输出JSON + 前端解析 | 零后端改动，灵活可控 |

| 历史记录页面 | 新增独立AnalysisHistory.tsx | 职责分离，不增加AIAnalysis复杂度 |
| 后端改动 | 零改动 | 所有API已存在：GetAIResponseResultList/Delete/BatchDelete |
| 自选股列表式分析 | AIAnalysis改造为多卡片列表 | 参考Vue版截图样式 |

#### 6.1.2 JSON解析函数

```typescript
// 从LLM输出中提取JSON结构化数据
function parseStructuredData(content: string): {
  structured: StructuredAnalysisData | null;
  markdown: string;
} {
  // 正则匹配第一个 ```json ... ``` 代码块
  const jsonBlockRegex = /```json\s*([\s\S]*?)```/;
  const match = content.match(jsonBlockRegex);
  
  if (!match) {
    return { structured: null, markdown: content };
  }
  
  try {
    const parsed = JSON.parse(match[1].trim());
    // 验证必要字段存在
    if (typeof parsed.overallScore !== 'number' || !parsed.recommendation) {
      return { structured: null, markdown: content };
    }
    // 提取JSON块之后的Markdown内容
    const jsonBlockEnd = content.indexOf(match[0]) + match[0].length;
    const markdown = content.substring(jsonBlockEnd).trim();
    return { structured: parsed as StructuredAnalysisData, markdown };
  } catch {
    return { structured: null, markdown: content };
  }
}
```

#### 6.1.6 单股票分析流程（startSingleAnalysis）

```typescript
const startSingleAnalysis = useCallback(async (stockCode: string, stockName: string) => {
  // 并发锁检查
  if (analyzingStocksRef.current.has(stockCode)) return;
  analyzingStocksRef.current.add(stockCode);

  // 为这只股票生成唯一事件名，避免多股并发事件混淆
  const eventName = `newChatStream`;  // 注意：后端只发这个事件名，所以同一时间只能分析一只
  
  // 重置该股票状态
  updateStockAnalysis(stockCode, {
    isAnalyzing: true,
    phase: 'collecting',
    content: '',
    structuredData: null,
    markdownContent: '',
    error: '',
    showDetail: false,
  });
  
  const contentAccumulator = { current: '' };
  const chatIdAccumulator = { current: '' };
  const question = buildAnalysisQuestion(stockName, stockCode);
  
  // 超时保护
  const timeoutId = setTimeout(() => {
    EventsOff(eventName);
    analyzingStocksRef.current.delete(stockCode);
    updateStockAnalysis(stockCode, {
      isAnalyzing: false,
      phase: 'timeout',
    });
  }, 60000);
  
  // 阶段推进定时器
  const phaseTimer1 = setTimeout(() => updateStockAnalysis(stockCode, { phase: 'analyzing' }), 5000);
  const phaseTimer2 = setTimeout(() => updateStockAnalysis(stockCode, { phase: 'generating' }), 10000);
  
  // 注册事件监听
  EventsOn(eventName, (msg: any) => {
    if (msg === 'DONE') {
      clearTimeout(timeoutId);
      clearTimeout(phaseTimer1);
      clearTimeout(phaseTimer2);
      EventsOff(eventName);
      analyzingStocksRef.current.delete(stockCode);
      
      const finalContent = contentAccumulator.current;
      const { structured, markdown } = parseStructuredData(finalContent);
      
      updateStockAnalysis(stockCode, {
        isAnalyzing: false,
        phase: 'completed',
        content: finalContent,
        structuredData: structured,
        markdownContent: markdown,
      });
      
      // 保存结果
      SaveAIResponseResult(stockCode, stockName, finalContent, chatIdAccumulator.current, question, selectedAiConfigId);
    } else if (typeof msg === 'object' && msg !== null) {
      if (msg.chatId) chatIdAccumulator.current = msg.chatId;
      if (msg.content) {
        contentAccumulator.current += msg.content;
        // 实时更新内容（打字机效果）
        const { structured, markdown } = parseStructuredData(contentAccumulator.current);
        updateStockAnalysis(stockCode, {
          content: contentAccumulator.current,
          structuredData: structured,
          markdownContent: markdown,
        });
      }
    }
  });
  
  try {
    const config = aiConfigs.find(c => c.ID === selectedAiConfigId);
    if (!config) {
      throw new Error('未选择AI模型配置');
    }
    await NewChatStream(stockName, stockCode, question, selectedAiConfigId, null, true, false);
  } catch (err: any) {
    clearTimeout(timeoutId);
    clearTimeout(phaseTimer1);
    clearTimeout(phaseTimer2);
    EventsOff(eventName);
    analyzingStocksRef.current.delete(stockCode);
    updateStockAnalysis(stockCode, {
      isAnalyzing: false,
      phase: 'error',
      error: err?.message || '分析失败',
    });
  }
}, [aiConfigs, selectedAiConfigId]);
```

// 注意：由于后端事件名是固定的 'newChatStream'，
// 同一时间只能分析一只股票，所以"一键分析全部"采用串行队列方式
const analyzeAll = useCallback(async () => {

          resolve();

## 8. 风险与应对

| 风险 | 应对策略 |
|------|----------|
| LLM不按格式输出JSON | parseStructuredData fallback到Markdown展示 |
| JSON格式不完整（流式中途） | 只在DONE后做最终解析，流式中实时尝试但不强制 |
| 自选股数量多导致初始化慢 | 历史结果批量加载用Promise.all但不阻塞UI |
| 后端事件名固定无法并行分析 | 一键分析采用串行队列，UI上禁用已在分析中的股票按钮 |
| renderMarkdown/parseContentSections 重复定义 | 可提取为 utils 文件，但本次为减少改动量在各文件内各自定义 |

## 9. 验收标准

1. AI分析页面显示自选股列表，每只股票一个结构化卡片
2. 卡片包含：综合评分+星级、推荐标签、四维评分、AI洞察、目标价
3. 点击"展开详情"显示完整Markdown分析
4. JSON解析失败时自动降级为Markdown分块展示
5. "一键分析全部"按钮串行分析所有自选股
6. 手动输入股票可触发分析
7. 分析历史页面可搜索、筛选、分页、删除记录
8. 侧边栏显示"分析历史"菜单项
9. npm run build 零错误零警告
