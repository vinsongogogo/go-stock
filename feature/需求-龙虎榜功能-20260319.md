## 二、业务通识摘要

### 2.1 龙虎榜业务概念

龙虎榜是交易所每日公布的异常交易股票榜单，包含以下关键信息：
- **上榜股票**：当日出现异常波动的股票
- **上榜原因**：如"日涨幅偏离值达7%"、"日换手率达20%"等
- **买卖金额**：龙虎榜买入额、卖出额、净买额
- **成交占比**：龙虎榜成交额占市场总成交的比例

## 三、现状与代码结论

### 3.1 后端 API 现状

**接口签名：**
```go
func (a *App) LongTigerRank(date string) *[]models.LongTigerRankData
```

**数据来源：** 东方财富数据中心
- URL: `https://datacenter-web.eastmoney.com/api/data/v1/get`
- 数据已持久化到数据库表 `long_tiger_rank`

**数据模型字段：**
| 字段 | 说明 | 前端展示 |
|-----|------|---------|
| SECUCODE | 股票代码 | ✅ 展示 |
| SECURITY_NAME_ABBR | 股票名称 | ✅ 展示 |
| TRADE_DATE | 交易日期 | ✅ 展示 |
| CLOSE_PRICE | 收盘价 | ✅ 展示 |
| CHANGE_RATE | 涨跌幅 | ✅ 展示 |
| BILLBOARD_NET_AMT | 龙虎榜净买额 | ✅ 展示 |
| BILLBOARD_BUY_AMT | 龙虎榜买入额 | ✅ 展示 |
| BILLBOARD_SELL_AMT | 龙虎榜卖出额 | ✅ 展示 |
| BILLBOARD_DEAL_AMT | 龙虎榜成交额 | ✅ 展示 |
| TURNOVERRATE | 换手率 | ✅ 展示 |
| FREE_MARKET_CAP | 流通市值 | ✅ 展示 |
| EXPLANATION | 上榜原因 | ✅ 筛选 + 展示 |

### 3.2 Vue 前端实现参考

**功能特性：**
1. **日期选择器**：默认当天，支持历史日期查询
2. **自动回退**：当天无数据时自动查询前一日（最多回退7天）
3. **上榜原因筛选**：支持下拉筛选不同上榜原因
4. **数据表格展示**：
   - 股票代码、名称
   - 收盘价、涨跌幅（红涨绿跌）
   - 龙虎榜买卖金额（万元）
   - 换手率、流通市值
   - 上榜原因
5. **交互功能**：
   - 股票名称悬停显示 K 线图
   - 净买额悬停显示资金流向图
