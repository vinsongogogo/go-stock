## 3. 数据与接口

- **数据模型**：无变更。前端 state 形状、各组件 ref/computed 与现有一致，仅 UI 与样式重写。
- **API**：无变更。继续使用 `wailsjs/go/main/App` 与 `wailsjs/runtime` 的现有导出，函数名、参数、语义不改。
- **前端路由与状态**：
  - **路由表**：path、name、component 与当前一致，不做重命名。
    - `/` → stock，`/market` → market，`/fund` → fund，`/agent` → agent，`/research` → research，`/settings` → settings，`/about` → about，`/cron-tasks` → cronTasks。
  - **TopNav 与行情**：TopNav 的 tab 与现有行情子项一一对应，点击后 `router.push({ name: 'market', query: { name: '<子项名>' } })` 且 `EventsEmit("changeMarketTab", { ID: 0, name: '<子项名>' })`。子项名沿用：市场快讯、全球股指、重大指数、行业排名、个股资金流向、龙虎榜、个股研报、公司公告、行业研究、当前热门、指标选股、名站优选。
  - **MarketTicker 数据源**：
    - **telegraph**：仅在此展示。数据来源：主进程通过 `EventsOn("telegraph", ...)` 下发的数组（与现有一致），在 MarketTicker 内展示为横向滚动项（可与指数混合或分段展示，见 5.4）。
    - **指数**：沿用 `GlobalStockIndexes()`（或现有 market 页内使用的指数接口），在 App 或 MarketTicker 内请求，将结果传入 MarketTicker 展示；格式与现有一致。
  - **activeKey**：与现有一致（stock、market、fund、agent、research、settings、about、full、hide、exit），用于侧栏高亮与 Naive 菜单。

## 4. 跨域/对外协议

本期为前端重写，**不新增、不修改**与 Go 的契约；以下为沿用约定汇总，确保重写后仍满足。

| 域/系统 | 协议形式 | 端点/事件/方法 | 说明 |
|---------|----------|----------------|------|
| 前端 ↔ Go (Wails) | Wails Call | `wailsjs/go/main/App` 下所有已用函数 | 函数名、参数、返回值不变；重写时仅允许封装为 composable/service，调用处仍使用相同函数与参数。 |
| 前端 ↔ Go (Wails) | EventsOn | `telegraph`、`loadingMsg`、`newsPush`、`realtime_profit` | payload 与现有一致；telegraph 仅用于 MarketTicker。 |
| 前端 → Go | EventsEmit | `changeTab`、`changeMarketTab`、`changeResearchTab`、`frontendError`、`loadingDone` | payload 与现有一致（如 changeTab: `{ ID, name }`，changeMarketTab/changeResearchTab: `{ ID, name }`）。 |
| 窗口/运行时 | wailsjs/runtime | WindowSetTitle、WindowHide、Quit、WindowFullscreen、WindowUnfullscreen 等 | 用法不变。 |

- **错误码与重试**：不涉及新协议；现有前端错误上报（frontendError）保持。
- **兼容与版本**：路由 path/name 不变，书签与深链无需兼容层。

## 5. 代码级设计（含代码/伪代码）

### 5.1 主框架布局与视觉（App.vue）

- **涉及文件**：`frontend/src/App.vue`、`frontend/src/style.css`（或 `frontend/src/theme/vars.css`）
- **逻辑说明**：全屏深色渐变背景 + 固定装饰光斑（无交互）；左侧固定侧栏 + 右侧主内容区；主内容区自上而下：TopNav → MarketTicker → RouterView（n-scrollbar 或 div 包裹）。保留 n-config-provider、n-message-provider、n-notification-provider、n-modal-provider、n-dialog-provider、FloatingAiAssistant；保留 loading、loadingMsg、EventsOn("loadingMsg"/"telegraph"/"newsPush"/"realtime_profit")、EventsOff、GetConfig、GetGroupList、GetVersionInfo、menuOptions 动态构建（GetGroupList 后拼自选分组）、WindowSetTitle("大聪明")。
- **样式约定**：根容器使用深色渐变（与 reference 一致），例如 `background: linear-gradient(to bottom right, #020617, #172554, #0f172a)`；光斑用固定定位的 div，大圆 + 模糊，例如 `background: rgba(59, 130, 246, 0.1); border-radius: 50%; filter: blur(80px); width/height: 24rem;`，位置参考 reference_style（左上、右侧、左下等）。主内容区背景与侧栏背景用 CSS 变量（见 6）。

**伪代码（结构）：**

```vue
<!-- frontend/src/App.vue 根结构 -->
<template>
  <n-config-provider :theme="enableDarkTheme" :locale="zhCN" :date-locale="dateZhCN">
    <n-message-provider><n-notification-provider><n-modal-provider><n-dialog-provider>
      <FloatingAiAssistant />
      <div class="app-root"> <!-- 深色渐变 + 光斑 -->
        <div class="app-bg-blurs" aria-hidden="true">
          <div class="app-blur app-blur--blue" />
          <div class="app-blur app-blur--purple" />
          <div class="app-blur app-blur--cyan" />
        </div>
        <div class="app-main">
          <AppSidebar v-model:collapsed="sidebarCollapsed" ... /> <!-- 或继续用 n-layout-sider，样式覆盖为 reference 风格 -->
          <div class="app-content">
            <TopNav :active-tab="marketTabName" @tab-change="onMarketTabChange" />
            <MarketTicker :telegraph="telegraph" :indexes="marketIndexes" />
            <n-spin :show="loading" ...>
              <div class="app-view"><RouterView /></div>
            </n-spin>
          </div>
        </div>
      </div>
    </n-dialog-provider></n-modal-provider></n-notification-provider></n-message-provider>
  </n-config-provider>
</template>
```

- **marketTabName**：由 `route.name === 'market' ? route.query.name : ''` 推导，用于 TopNav 高亮。
- **onMarketTabChange(name)**：`router.push({ name: 'market', query: { name } })` + `EventsEmit("changeMarketTab", { ID: 0, name })`。
- **marketIndexes**：在 App.vue 的 onMounted 中调用 `GlobalStockIndexes()`，将返回结果传入 MarketTicker（格式与 market.vue 现有使用一致）。
- **telegraph**：继续由 `EventsOn("telegraph", (data) => { telegraph.value = data })` 更新，并作为 props 传给 MarketTicker。

### 5.3 TopNav 组件

- **涉及文件**：`frontend/src/components/layout/TopNav.vue`（新建）
- **逻辑说明**：横向可滚动 tab 列表，与行情子项一一对应；当前 tab 与 `route.name === 'market' && route.query.name` 同步；选中态：文字 cyan + 底部渐变线。点击 tab 时触发 `@tab-change(name)`，由父组件（App.vue）执行 `router.push` + `EventsEmit("changeMarketTab", ...)`。
- **props**：`activeTab: String`（当前选中的子项名，如「市场快讯」）。
- **events**：`@tab-change(name: string)`。
- **代码/伪代码**：

```vue
<!-- TopNav.vue 简化 -->
<template>
  <div class="top-nav">
    <div class="top-nav-scroll">
      <button
        v-for="tab in marketTabs"
        :key="tab"
        :class="['top-nav-tab', { 'is-active': activeTab === tab }]"
        @click="$emit('tab-change', tab)"
      >
        {{ tab }}
        <span v-if="activeTab === tab" class="top-nav-tab-line" />
      </button>
    </div>
  </div>
</template>
<script setup>
defineProps<{ activeTab: string }>();
defineEmits<{ (e: 'tab-change', name: string): void }>();
const marketTabs = [
  '市场快讯', '全球股指', '重大指数', '行业排名', '个股资金流向',
  '龙虎榜', '个股研报', '公司公告', '行业研究', '当前热门', '指标选股', '名站优选'
];
</script>
```

- 样式：`.top-nav` 背景半透明、backdrop-blur、底边白线；`.top-nav-tab.is-active` 为 cyan；`.top-nav-tab-line` 为底部渐变线（如 linear-gradient(to right, cyan, blue)）。

### 5.4 MarketTicker 组件（telegraph 仅在此展示）

- **涉及文件**：`frontend/src/components/layout/MarketTicker.vue`（新建）
- **逻辑说明**：单行横向滚动条，展示指数（名称 + 数值 + 涨跌颜色）与 telegraph 数据；telegraph **只在此区域展示**，不再使用 n-marquee。数据来源：父组件传入 `telegraph`（数组）与 `indexes`（GlobalStockIndexes 返回结构）；可合并为同一滚动条或分两段（先指数后 telegraph），由实现决定；需支持无限循环滚动（双份数据 + CSS animation 或 JS 滚动）。
- **props**：`telegraph: Array`（字符串数组或与现有 payload 一致）、`indexes: Object | null`（与 GlobalStockIndexes 一致，如 common/america/europe/asia/other）。
- **代码/伪代码**：将 indexes 展平为列表项（name、code/value、change、isUp），与 telegraph 项一起组成 tickerItems；渲染为一行，每项为「名称 + 数值 + 涨跌」；涨用 green、跌用 red；容器 `overflow: hidden`，内部 `display: flex` 双份 tickerItems，`animation: scroll 30s linear infinite`（需在 style.css 定义 @keyframes scroll，translateX(-50%)）。
- **样式**：与 reference MarketTicker 一致，背景略透明、底边细线、scrollbar-hide。

### 5.5 子页面与卡片风格（统一视觉，逻辑与接口不变）

- **涉及文件**：`frontend/src/components/` 下所有页面与子组件（stock.vue、market.vue、researchIndex.vue、settings.vue、about.vue、agent-chat.vue、cron-task-manager.vue、fund.vue 以及 newsList、KLineChart、rankTable、FloatingAiAssistant 等）
- **逻辑说明**：各页面**功能与业务逻辑、调用的 wailsjs 接口、EventsOn/EventsEmit、路由与 query** 与现有一致；仅 UI 重写为深色背景、圆角毛玻璃卡片（半透明 + backdrop-blur、白边、hover 时 cyan 边框）、标题区可带色条；列表/新闻类采用类似 reference NewsFeed 的卡片列表。Naive 组件通过 NConfigProvider 的 themeOverrides 或全局 CSS 变量改为深色主题；卡片使用统一 class（如 `.card-glass`）在 style.css 或公共样式中定义。
- **卡片样式约定**（在 style.css 或 theme 中）：

```css

  background: rgba(15, 23, 42, 0.4);
  backdrop-filter: blur(24px);
  border-radius: 1rem;
  border: 1px solid rgba(255, 255, 255, 0.1);
  transition: border-color 0.2s;

```

- 涨/跌颜色：沿用绿色（涨）、红色（跌），与 reference 一致；主强调色 cyan 用于边框、链接、选中态。

  - `--app-bg`：深色渐变或主色（#0f172a / #172554 等）
  - `--sidebar-bg`：侧栏毛玻璃（rgba(15,23,42,0.5)）
  - `--content-bg`：内容区背景
  - `--border-color`：rgba(255,255,255,0.1)
  - `--accent-cyan`：#22d3ee 或 oklch 等价
  - `--text-primary`、`--text-secondary`、`--up`（涨）、`--down`（跌）
- **Naive UI**：通过 `n-config-provider` 的 `theme` 传入 `darkTheme`（来自 GetConfig().darkTheme），或通过 `themeOverrides` 覆盖组件 token，使全局为深色。
- **与 reference 的对应**：reference 的 `from-slate-950 via-blue-950 to-slate-900`、`bg-slate-900/40`、`border-white/10`、`text-cyan-400`、`blur-3xl` 等，用上述 CSS 变量 + 手写 class 实现，不引入 Tailwind。
