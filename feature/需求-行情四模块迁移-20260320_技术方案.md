# 技术方案：行情四模块迁移（对应 `feature/需求-行情四模块迁移-20260320.md`）

## 范围与目标

在 `frontend` 用 React + 既有 Wails API 替换 `frontend_vue` 中四块能力，样式对齐现有 `Dashboard` / `MoneyFlow` 外壳（`bg-slate-900/40`、`text-xs` 表格、`SubMenu` 按钮条）。

## 架构与模块

- **`MoneyFlow.tsx`**：容器；一级 Tab + 条件渲染四个子面板。
- **`frontend/src/app/components/market/StockMoneyFlowPanel.tsx`**：`GetMoneyRankSina` + 子排序 Tab + 表格 + `Popover` + `KLineChart`。
- **`frontend/src/app/components/market/IndustryRankPanel.tsx`**：`GetIndustryRank` + 二级 Tab（涨幅 / 三类资金）+ `GetIndustryMoneyRankSina` + 领涨股 `KLineChart`。
- **`frontend/src/app/components/market/GlobalIndexesPanel.tsx`**：`GlobalStockIndexes` 分区网格。
- **`frontend/src/app/components/market/StockNoticePanel.tsx`**：`GetStockList` 搜索 + `StockNotice` + `BrowserOpenURL` + 悬停 `MoneyTrend` / `KLineChart`。

## 跨域/对外协议

- 全部通过 `wailsjs/go/main/App` 与 `wailsjs/runtime` 已有绑定，无新增 HTTP 协议。
