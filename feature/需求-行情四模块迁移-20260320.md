# 需求：行情四模块迁移（frontend_vue → frontend）

## 需求概述

将 `frontend_vue` 市场行情中的 **个股资金流向**、**行业排名**（含行业涨幅与行业/板块资金排名）、**全球指数**（分区列表）、**个股公告** 迁移到 React 前端 `frontend`，视觉与字号以当前 `frontend`（Tailwind、卡片玻璃态、`text-xs` 表格）为准。

## 业务通识摘要

- 数据均来自既有 Wails `App` 绑定：`GetMoneyRankSina`、`GetIndustryRank`、`GetIndustryMoneyRankSina`、`GlobalStockIndexes`、`StockNotice`、`GetStockList`。
- 与 `knowledge/common.md` 中龙虎榜等模块一致：K 线/资金图使用 `KLineChart`、`MoneyTrend`。

## 现状与代码结论

- `frontend_vue`：`market.vue` + `rankTable.vue`、`industryMoneyRank.vue`、`StockNoticeList.vue`。
- `frontend`：`MoneyFlow.tsx` 为占位模拟数据；`MarketTicker` 已用 `GlobalStockIndexes` 做顶部滚动，需在「全球指数」页提供完整分区展示。

## 待产品确认

（无 — 范围与数据源已由用户指定。）

## 澄清后需求明细

1. **入口**：侧边栏「资金流向」进入后，顶部一级 Tab：**个股资金流向 | 行业排名 | 全球指数 | 个股公告**。
2. **个股资金流向**：与 Vue `rankTable` 一致的排序维度（`netamount` / `outamount` / …）；真实调用 `GetMoneyRankSina`；名称悬停展示 K 线（与龙虎榜交互一致）；约 60s 自动刷新。
3. **行业排名**：子模块包含行业涨幅表（`GetIndustryRank`，可切换排序）、三类行业/板块资金表（`GetIndustryMoneyRankSina`，`fenlei` 0/2/1）；领涨股悬停 K 线。
4. **全球指数**：展示 `GlobalStockIndexes` 返回的常用/美洲/欧洲/亚洲/其他分区列表（名称、现价、涨跌幅、开市状态）；定时刷新。
5. **个股公告**：支持搜索（`GetStockList`）并查询 `StockNotice`；列表字段与 Vue 一致；公告链接用 `BrowserOpenURL`；股票悬停 K 线/资金图与 Vue 一致。
