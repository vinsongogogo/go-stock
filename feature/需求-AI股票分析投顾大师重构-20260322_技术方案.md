## 3. 架构与数据流

```
GetDashboardPromptID → NewChatStream(sysPromptId) → LLM
  → 首段 JSON (advisor_master_v1) + 可选 Markdown
  → 前端 parseAiAnalysisPayload → AdvisorMasterPanel | 旧仪表盘 | 旧评分 | Markdown
```

## 4. JSON 协议（advisor_master_v1）

根字段（与 UI 强相关）：

- `schema_version`: `"advisor_master_v1"`
- `stock_name`, `sentiment_score`（0–100）, `sentiment_label`, `trend_prediction`, `operation_advice`, `confidence_level`, `analysis_summary`
- `market_position`: `stock_quote`, `market_quote`, `relative_strength`, `volatility_character`, `market_cap_tier`
- `multi_factor`: `valuation`, `growth`, `momentum`, `quality`, `sentiment`
- `risk_alert`: `gray_rhino`, `black_swan`
- `tactical`: `trend_following`, `contrarian`
- `tracking_memo`: `next_key_time_node`, `volume_price_alert`
- `four_dimensions`: `fundamental`, `industry`, `capital`, `technical`
- `professional_dimensions`: `static_valuation`, `dynamic_valuation`, `volatility`, `institution_research`
- `actionable`: `stop_loss_triggers`, `suggested_position`, `buy_reason`, `sell_reason`

均为字符串或可省略；由模型基于上下文填写。
