# 需求文档：frontend 风格和结构优化（按 reference_style 全部重写，核心逻辑与接口保持一致）

## 1. 需求概述

- **目标**：按项目内 `reference_style/` 的格式与样式，对 `frontend/` 进行**全部重新编写**；在重写过程中**核心逻辑与接口与之前保持一致**（不改变与后端的契约、路由与业务行为）。
- **背景/价值**：产品希望前端在视觉与结构上向 reference_style 靠拢，并明确采用「全部重写」方式落地，同时保证功能与对接不变，降低后端与集成风险。

## 2. 业务通识摘要

- **当前无 `通识.md`**，建议在项目根或 `docs/` 下补充业务名词与规则。
- 与本需求相关的约定：
  - 应用为 **Wails 桌面端**，前端技术栈：**Vue 3 + Vite**，**Naive UI**，Vue Router（Hash）。
  - 主窗口标题为「大聪明」；主导航为左侧边栏 + 右侧内容区；路由包括：自选（stock）、行情（market）、基金（fund）、智能助手（agent）、研究（research）、设置（settings）、关于（about）、计划任务（cronTasks）等。
  - **reference_style** 为仓库内独立参考项目：**React + Vite + Tailwind CSS**，用于展示「大盘阴」风格的行情/资讯界面；本需求仅**借鉴其格式与样式**，不切换技术栈，不引入 Tailwind（沿用现有 CSS 变量 + Naive/手写样式）。

### 3.5 与需求差异小结

- 需求为「全部重新写」+「核心逻辑和接口保持一致」。当前项目在布局层次、视觉体系、卡片与内容区形态上与 reference_style 不一致，且产品明确要求**全部重写**而非局部优化。差异部分通过重写解决；一致部分通过约束（路由、接口、事件、业务能力）在重写中保留。
