# 需求-AI股票分析投顾大师重构-20260322

## 1. 需求概述

- **目标**：重构「AI 股票分析」模块的系统人设与输出协议，采用「30 年实战经验顶级股票投顾大师」人设（含缠论中枢与多策略维度），分析报告按固定 8 段顺序结构化输出；前端提供与协议一致的可视化 UI（深色/glass 风格与现有页面统一）。
- **背景/价值**：统一投顾表达与数据契约，提升结论可读性与可验收性，并与设置中的「决策仪表盘」系统 Prompt 联动。

## 2. 业务通识摘要

（摘自 `knowledge/common.md`「AI 股票分析功能」）

- **入口**：Sidebar「AI股票分析」、`AIAnalysis.tsx`。

- **既有能力**：旧版决策仪表盘 JSON（`dashboard` 嵌套）、更旧版评分 JSON（`overallScore` 等）、Markdown 降级展示。

## 5. 澄清后需求明细

### 5.1 系统 Prompt（决策仪表盘模板）

- **描述**：`DefaultDashboardPrompt` 替换为：用户提供的投顾人设与知识要点（宏观/行业/基本面/策略与风控/行为金融/交易技巧/持续学习/缠论中枢与背驰等）；明确总结标题形式：`{{stockName}}[{{stockCode}}]分析和总结`（由后端已有占位符替换）。
- **输出协议**：必须先输出唯一一个 ` ```json ` 代码块，内含 `schema_version: "advisor_master_v1"` 与 8 个逻辑段对应字段；允许在 JSON 块之后输出补充 Markdown。数值与结论须基于系统提供的行情/财务/资讯等，禁止编造未提供数据。
- **验收标准**：新安装或从旧默认模板升级后，分析结果首段 JSON 可被前端解析为 `advisor_master_v1`；历史旧格式仍可展示。

### 5.2 结构化报告 8 段顺序（与 JSON 字段对齐）

1. 行情定位：个股/大盘/相对强弱/波动特征/市值坐标  
2. 多因子透视：估值、成长、动量、质量、情绪  
3. 风险预警：灰犀牛（系统性风险）、黑天鹅  
4. 战术建议：趋势跟踪、逆向投资  
5. 跟踪备忘录：下阶段关键交易时间节点（结合 5 日均线与 5 日平均成交量）、量价预警阈值  
6. 四维分析：基本面、行业面、资金面、技术面（含 ROE/现金流/政策周期/主力与筹码/指标共振等）  
7. 专业维度：静态估值、动态估值、波动性、机构调研（用户文案「专业将维」按「专业维度」呈现）  
8. 具体操作建议：止损/止跌触发条件、建议仓位、买入理由、卖出理由  

### 5.3 前端 UI

- **描述**：新增「投顾大师」结构化面板组件，按 8 段分区展示（卡片/栅格，与现有 `DashboardCard`、深色主题一致）；解析优先级：`advisor_master_v1` > 旧 `dashboard` JSON > 旧评分 JSON > Markdown。
- **验收标准**：流式完成后与历史记录切换时展示正确；左侧列表评分仍可优先使用 `sentiment_score`（若存在）。

### 5.4 数据与兼容

- **描述**：对已写入数据库且内容仍以旧默认仪表盘 Prompt 开头的记录，启动时将该条 `type=dashboard` 模板更新为新默认（用户若在设置中深度自定义且不以该前缀开头，则不覆盖）。
- **验收标准**：升级后新分析走新协议；旧缓存分析结果仍能打开。
