## 功能需求明细

### FR-01 结构化分析结果展示

将 AI 分析结果从 Markdown 文本改为结构化卡片样式，参考 Vue 版 AI 诊断截图：

每只股票的分析结果卡片包含以下结构化区域：

1. 头部区域：
   - 股票名称 + 股票代码
   - 推荐等级标签（强烈买入/买入/持有/卖出/强烈卖出），不同等级不同颜色
   - AI 综合评分（0-100 分数 + 星级评定，1-5星）
   - 更新时间

2. 四维评分卡片（水平排列）：
   - 技术面评分（0-100）+ 图标
   - 基本面评分（0-100）+ 图标
   - 资金面评分（0-100）+ 图标
   - 风险等级（低风险/中风险/高风险）+ 图标

3. AI 智能洞察区域：
   - Brain 图标 + "AI智能洞察" 标题
   - 一段综合分析文字摘要

4. AI 预测目标价区域：
   - 三列目标价卡片：悲观价格 / 中性价格 / 乐观价格
   - 每个卡片有不同底色（悲观-青绿、中性-深灰、乐观-紫粉）

5. 展开详情：
   - 点击"展开详情"显示完整的 AI 分析 Markdown 内容（技术分析详情、基本面详情、行业对比等原有文字分析）

### FR-02 Prompt 引导结构化输出

在调用 NewChatStream 时，构造的分析问题中嵌入以下引导 prompt，要求 LLM 先输出 JSON 结构化数据，再输出详细 Markdown 分析：

分析问题模板（question 参数）：

```
请对 {stockName}({stockCode}) 进行全面深度分析。

【重要】请严格按以下格式输出分析结果：

第一部分：请先输出一个 JSON 代码块，包含结构化评估数据，格式如下：
```json
{
  "overallScore": 78,
  "recommendation": "买入",
  "technicalScore": 53,
  "fundamentalScore": 74,
  "capitalScore": 78,
  "riskLevel": "低风险",
  "aiInsight": "一句话综合分析摘要，不超过100字",
  "targetPrice": {
    "pessimistic": 63.21,
    "neutral": 108.45,
    "optimistic": 97.07
  }
}
```

字段说明：
- overallScore：综合评分，0-100 整数
- recommendation：推荐等级，只能是以下之一：强烈买入、买入、持有、卖出、强烈卖出
- technicalScore：技术面评分，0-100 整数
- fundamentalScore：基本面评分，0-100 整数
- capitalScore：资金面评分，0-100 整数
- riskLevel：风险等级，只能是以下之一：低风险、中风险、高风险
- aiInsight：AI 智能洞察摘要，一句话概括分析结论
- targetPrice：目标价位预测，pessimistic(悲观)、neutral(中性)、optimistic(乐观)，保留两位小数

第二部分：在 JSON 代码块之后，输出详细的 Markdown 格式分析报告，包含以下章节：
## 技术面分析
MACD、RSI、均线、KDJ 等指标解读

## 基本面分析
市盈率、市净率、ROE 等财务指标分析

## 资金流向分析
主力资金、散户资金动向

## 市场情绪分析
近期新闻舆论导向

## 行业对比分析
在所属行业中的竞争地位

## 财报深度解读
最新财报关键数据及同比变化

## 风险评估与投资建议
综合风险评估和具体操作建议

请基于提供的数据进行分析，不要编造不存在的数据。所有评分和目标价必须基于实际分析给出合理数值。
```

前端解析策略：

1. 从流式内容中检测 ```json 开头的代码块，提取并解析 JSON
2. JSON 解析成功：渲染结构化卡片（评分、推荐、目标价等）+ 后续 Markdown 详情
3. JSON 解析失败或格式不完整：fallback 到现有的 Markdown 分块展示模式
4. JSON 提取使用正则：/```json\s*([\s\S]*?)```/ 匹配第一个 JSON 代码块

### FR-03 独立分析历史页面

新增一个"分析历史"页面，作为独立菜单项添加到侧边栏：

1. 页面功能：
   - 显示所有股票的 AI 分析历史记录列表
   - 支持按股票代码/名称搜索
   - 支持按日期范围筛选
   - 分页展示（每页10条）
   - 每条记录显示：股票名称、股票代码、分析时间、使用的 AI 模型、推荐等级
   - 点击记录可展开查看完整分析内容
   - 支持删除单条和批量删除

2. 后端 API（已有，直接复用）：
   - GetAIResponseResultList：分页查询，支持 stockCode/stockName/日期范围筛选
   - DeleteAIResponseResult：单条删除
   - BatchDeleteAIResponseResult：批量删除

3. 侧边栏菜单：
   - 在 Sidebar.tsx 底部菜单区域新增"分析历史"菜单项（History 图标）
   - App.tsx 路由新增 'analysisHistory' view

参考截图，AI分析页面应该以列表形式展示所有自选股的分析卡片（每只股票一个卡片），而不是选一只股票后只显示一个分析结果。

1. 页面顶部显示"分析股票数 N"
2. 自动对自选股列表中的股票显示分析结果卡片（从历史结果加载）
