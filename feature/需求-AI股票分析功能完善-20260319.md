# 需求文档：AI股票分析功能完善

**文档版本**: v1.0  
**创建日期**: 2026-03-19  
**状态**: 已澄清

---

## 1. 背景

当前 go-stock 项目的 AIAnalysis.tsx 页面（463行）已有完整的UI界面，展示了技术分析、基本面分析、资金流向、市场情绪、风险评估、目标价格、AI洞察等维度的分析卡片。但目前展示的数据是静态/模拟数据，未接入后端 backend/agent 的真实 AI 能力。

后端 backend/agent 已有完整的 ReAct Agent 系统，包含12个工具：

| 序号 | 工具名称 | 功能说明 |
|------|----------|----------|
| 1 | GetQueryEconomicDataTool | 经济数据查询 |
| 2 | GetQueryStockPriceInfoTool | 股票实时价格 |
| 3 | GetQueryStockCodeInfoTool | 股票代码/基本信息 |
| 4 | GetQueryMarketNewsTool | 市场新闻 |
| 5 | GetChoiceStockByIndicatorsTool | 按指标筛选股票 |
| 6 | GetStockKLineTool | K线数据 |
| 7 | GetInteractiveAnswerDataTool | 交互式答案数据 |
| 8 | GetFinancialReportTool | 财务报告 |
| 9 | GetQueryStockNewsTool | 股票新闻 |
| 10 | GetIndustryResearchReportTool | 行业研究报告 |
| 11 | GetQueryBKDictTool | 行业板块字典 |
| 12 | common.go | 工具共享函数 |

前端已有 Wails IPC 绑定：ChatWithAgent、NewChatStream、SaveAIResponseResult、GetAIResponseResult 等。

---

## 2. 需求目标

将 AIAnalysis 页面从静态展示升级为真实 Agent 驱动的 AI 分析页面，复用 backend/agent 的能力和工具。

---

## 3. 功能需求明细

### FR-01 接入真实 Agent 分析

**需求描述**：  
将 AIAnalysis 页面的各分析维度数据从静态/模拟数据改为通过调用后端 Agent 获取真实分析结果。

**实现方式**：  
- 调用 NewChatStream 或 ChatWithAgent
- Agent 利用其工具（K线、财报、新闻等）生成分析报告
- 前端解析 Agent 返回的结构化数据并填充到各分析卡片中

**展示要求**：  
分析过程应该是流式的，用户能看到 Agent 正在分析的实时状态。

---

### FR-02 扩展分析维度

**需求描述**：  
在现有维度（技术分析、基本面、资金流向、市场情绪、风险评估、目标价、AI洞察）基础上，增加以下分析维度：

| 新增维度 | 依赖工具 | 展示内容 |
|----------|----------|----------|
| 行业对比分析 | GetQueryBKDictTool、GetIndustryResearchReportTool | 该股票在所属行业中的位置 |
| 财报深度解读 | GetFinancialReportTool | 关键财务指标及同比变化 |
| 研报摘要 | GetIndustryResearchReportTool | 最新研究报告要点 |

---

### FR-03 双触发方式

**需求描述**：  
支持两种触发分析的方式：

1. **从自选列表选择**  
   - 页面展示当前自选股票列表
   - 点击某只股票即可触发 Agent 分析

2. **手动输入**  
   - 提供股票代码输入框
   - 输入代码后点击分析按钮触发

---

### FR-04 分析结果持久化

**需求描述**：  
利用现有的 SaveAIResponseResult / GetAIResponseResult 接口实现分析结果持久化。

**具体行为**：  
- 分析结果自动保存
- 再次查看同一股票时可以加载历史分析结果
- 提供"重新分析"按钮允许用户获取最新分析

---

### FR-05 UI 风格统一

**需求描述**：  
保持现有 AIAnalysis 页面的设计风格：

- 深色主题
- glassmorphism 卡片效果
- cyan/blue 渐变色系

**要求**：  
新增的维度卡片风格与现有卡片保持一致。

---

### FR-06 Prompt 使用策略

**需求描述**：  
AI分析页面直接使用系统设置（Settings）中配置的全局 Prompt 作为系统提示词，不单独做 prompt 模板选择功能。调用 NewChatStream 时 sysPromptId 传 nil 或 0，自动 fallback 到全局 Prompt。

---

## 4. 非功能需求

| 类别 | 要求 |
|------|------|
| 流式展示 | Agent 分析过程应有加载动画和进度提示 |
| 错误处理 | Agent 调用失败时应有友好的错误提示 |
| 性能优化 | 避免频繁重复调用，已有分析结果应优先展示缓存 |
