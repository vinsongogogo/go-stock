# 项目通识（Common Knowledge）

本目录存放项目级通识，由「自我优化」技能在**功能完成**或**纠正沉淀**之后自动补充更新。

## 主文件

- **`common.md`**：业务与功能通识，包含各 feature 的入口、调用关系、使用目的、依赖服务/应用、关键设计原因等。供需求澄清、技术方案设计、实现与测试时参考。

## 更新时机

- 每次按技术方案完成实现（AI Coding 完成）后
- 开发流程中测试阶段通过后
- 完成一次用户纠正并写入 corrections 之后

详见 `.cursor/skills/self-optimization/SKILL.md` 中「构建通识」一节。
